# Moorberry.net

Michael Minter's portfolio and article archive, built with Astro. The home page is adapted from the Dark Minimal template in `TEMPLATE-LICENSE`.

## Develop

Requires Node.js 22.12+ and pnpm 9+.

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

Amplify serves the committed `dist/` files as a static site. The pre-commit hook builds locally and stages `dist/` automatically. To prepare a site update without the hook, run:

```sh
pnpm build
git add -A dist
```

The Amplify build spec does not invoke Node.js or install dependencies; it only publishes the committed files in `dist/`.

## Commit hook

Enable the repository's pre-commit hook after cloning:

```sh
git config core.hooksPath .githooks
```

The hook runs `pnpm build` before each commit, stages the generated `dist/` files, and blocks the commit if the build fails. If nvm is installed, it selects the Node.js version in `.nvmrc` first.

The deployable static site is generated in `dist/`. Posts are loaded from `content/blog`; article and topic pages are generated by Astro. The `/index.xml` and `/articles/index.xml` feeds are also generated. Assets and résumé PDFs live in `public/`.
